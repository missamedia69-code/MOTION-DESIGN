# Grammaire de storyboard et patterns de motion design

Repris de « Motion design avec Claude Code » (Colin Blain, licence MIT, voir `LICENSE`) :
patterns observés sur des films de motion design professionnels et modèles de storyboard.

Ils guident l'agent quand il écrit un storyboard sur mesure (`brief.scenes` de `./md pub`
/ `md_pub`) : variété des plans, raccords entre scènes, rythme calé sur la voix.

- `PATTERNS.md` : patterns de motion design (ce qui revient dans les bons films).
- `STORYBOARD-CRAFT.md` : comment écrire un storyboard plan par plan.
- `STORYBOARD-TEMPLATE.md`, `DIRECTIONS-TEMPLATE.md` : modèles à remplir.
